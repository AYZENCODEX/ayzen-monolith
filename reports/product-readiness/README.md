# Product readiness evidence

The Phase 1–40 scorecard is generated by:

```text
pnpm validate:product-readiness-1-40
```

The validator writes `reports/product-readiness/phase-1-40.json`. A numeric
score cannot override a hard blocker. Provider-backed phases remain marked in
the report until the staging environment supplies real database, event,
identity, mail, Telegram, storage, performance, restore, and rollback evidence.
