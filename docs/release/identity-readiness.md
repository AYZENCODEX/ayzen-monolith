# Hybrid identity readiness

The repository gate covers local-only use, verified AYZEN connection, explicit
link-later flow, profile ownership, app-scoped sessions, policy separation,
identity events, Telegram reuse, and negative security paths.

Live provider callback URLs, production database rollout, email/SMS delivery,
Telegram webhook activation, and cloud monitoring require environment-specific
configuration and approvals; this contract does not invent those values.
